# Gathering the data

The database was built by requesting public pages with `python -m src.collect`, not by downloading a prepared dataset. Steam search supplied game ids released from January 1, 2018 through March 31, 2026, spread across each year rather than taken only from December. Steam app details supplied the title, release date, genres, categories, and Metacritic score. Steam's review summary, limited to the first 30 days after release, supplied the early player score. SteamCharts monthly tables supplied average and peak concurrent players; SteamDB was not used because it blocks automated requests. Each search page contributed its most-reviewed game, and only when that game showed at least 1,000 lifetime reviews, because smaller games rarely have a public player chart. A first pass queued 60 games per year and a second pass raised that to 300, keeping games already saved. Requests paused between calls, retried rate limits, and cached finished pages. The database holds 2,406 games. Of those, 1,822 met the analysis rules: a full game, both month 1 and month 6 present, at least 50 average players in month 1, and at least 20 reviews in the first 30 days.
